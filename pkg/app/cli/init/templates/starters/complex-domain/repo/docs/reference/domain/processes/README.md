# Domain processes

Use domain processes for business or system operation that exists beyond one user-interface journey. Capture triggers, states, transitions, decisions, handoffs, invariants, exceptions, and the requirements that apply at each point. Link actor-facing paths to separate `UserWorkflow` notes instead of collapsing both models.
