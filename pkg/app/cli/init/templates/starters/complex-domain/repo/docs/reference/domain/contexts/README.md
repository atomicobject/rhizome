# Domain contexts

Use domain contexts when terms, rules, source evidence, and requirements need to be interpreted together within a business area, regulatory scope, external system boundary, or bounded model. Reuse an existing durable context where its boundary fits. Preserve competing definitions and source conflicts until evidence or an authorized decision resolves them.
