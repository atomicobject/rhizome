# User workflows

Use user workflows for an actor's goals, tasks, interaction paths, decisions, variants, exceptions, and friction. Link a workflow to a `DomainProcess` when the actor's journey participates in broader business or system operation. Keep unconfirmed variants explicit and link only the requirements supported by the evidence.
