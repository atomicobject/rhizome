# Domain types

Use domain types for concepts whose meaning, states, relationships, or invariants affect requirements or implementation. Link requirements only where evidence or an accepted domain decision supports the relation. Keep delivery behavior in specs and preserve unsettled vocabulary as explicit uncertainty or an accountable action item.
