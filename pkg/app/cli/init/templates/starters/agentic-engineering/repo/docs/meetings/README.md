# Meetings

## Summary

Use this folder for raw transcripts, structured meeting notes, SME conversations, sticky-note exports, research notes, and other source material that should retain provenance before it becomes durable specs, decisions, and reference docs.

## Rules

- prefer one canonical source artifact per meeting or source event
- use `YYYY-MM-DD-<slug>.txt` for raw transcript filenames
- treat these files as source inputs; durable conclusions belong in ontology-backed notes elsewhere in `docs/`
