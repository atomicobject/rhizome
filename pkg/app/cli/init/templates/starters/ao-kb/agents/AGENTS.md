## AO KB knowledge

- Use `ao-kb-setup` to install, check, refresh model bindings for, or recover the AO KB knowledge workspace. Module actions need a repository the user has trusted with `rzm trust`.
- Change knowledge through `/ao-kb:process`, `/ao-kb:curate`, or `/ao-kb:suggest`.
- AO KB notes are edited through Rhizome's editors like any other note; AO's own skills edit them too. Paths listed in `.rhizome/source-ownership.yml` belong to the tool that declared them; Rhizome refuses native edits to those, and that file is changed only on purpose, never to get around a refusal.
