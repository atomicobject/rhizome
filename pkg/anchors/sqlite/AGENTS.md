# SQLite test ownership

- Test current schema through `Open` and supported v56+ upgrades. Pre-v56 Intel state resets; do not test historical builders as upgrade paths.
- For deletion cleanup, capture row IDs before deleting and query stored edges directly. A lookup by a deleted logical ID hides dangling rows.
- Exercise snapshot and rollback behavior through public reads and real SQL failures. Do not add production callbacks solely to time or fail a test.
- Explain SQL generated by the production query builder, and give filtered searches an independent expected result with a restrictive limit.
