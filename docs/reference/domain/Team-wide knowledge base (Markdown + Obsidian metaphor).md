# Team-wide knowledge base (Markdown + Obsidian metaphor)

## Summary

Rhizome is designed so the whole team can contribute to durable system knowledge in Markdown. Wikilinks, tags, and hub-like navigation make the knowledge base accessible beyond the engineering team, while retrieval and code binding make it operational during implementation work.
