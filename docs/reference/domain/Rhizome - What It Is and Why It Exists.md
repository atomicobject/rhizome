# Rhizome - What It Is and Why It Exists

## Summary

Rhizome is infrastructure for AI-forward development. It connects a Markdown knowledge base to a codebase so agents can work inside system constraints, business rules, and project rationale without being re-taught every session.

## Core idea

Rhizome combines:

- a team-editable knowledge base in Markdown
- bidirectional code/documentation binding via coderefs and code anchors
- a unified local index for notes, code, graph signals, and semantic retrieval
- repeatable agent workflows built on top of the retrieval surface

## Knowledge funnel

Rhizome helps teams move from:

1. ambiguity
2. shared understanding
3. repeatable procedure

The goal is not just storing notes. It is turning durable system knowledge into operational context that both humans and agents can retrieve at the moment of work.
