# Agent Skills - Anthropic Skills Guide

## Summary

This note preserves the practical Anthropic Agent Skills rules that matter for Rhizome work: skill discovery, packaging, progressive disclosure, and environment constraints.

## Durable points

- `SKILL.md` metadata drives discovery
- supporting files should use progressive disclosure
- skill packaging rules and upload constraints are strict enough to matter during export or portability work
- Claude-hosted skill environments have tighter runtime constraints than local repo skills
