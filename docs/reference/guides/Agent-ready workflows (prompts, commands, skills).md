# Agent-ready workflows (prompts, commands, skills)

## Summary

Rhizome is not just an index. It is a workflow platform. Teams can package prompts, commands, and skills so AI-forward development becomes procedural and repeatable across environments such as Codex, Claude, and Cursor.

## Practical contract

- retrieval surfaces provide the shared knowledge substrate
- prompts and commands encode common higher-level tasks
- skills package repeatable multi-step agent workflows
- init scaffolding should make those workflow surfaces available without bespoke per-repo scripting
