# Guides

## Summary

Use this folder for evergreen guidance that supports execution but is not itself a normative spec.

## Using Rhizome

Read these in order after the repository README.

- [Getting started](getting-started.md): install Rhizome Desktop, set up or join a repository, connect your agent, and check that it works.
- [Using the skills](using-skills.md): where to work with your agent and which skill fits each kind of work.
- [Adapting Rhizome](adapting-rhizome.md): change team policy, skills, project data, views, and experiences.
- [Scheduled tasks](scheduled-tasks-guide.md): declare recurring agent work and handle the Tasks inbox.
- [Command-line reference](command-line.md): the `rzm` command for terminals, scripts, and installations without the desktop app.

## Starter guides

- `harness-capabilities.md` - how starter skills resolve across agent harnesses and when subagent delegation is available
- `ontology-driven-transcript-ingestion.md` — how transcript synthesis derives targets from the ontology instead of a fixed lens catalog

## Building on Rhizome

- `build-an-experience.md` - how to build an experience (a folder of views with `experience.yml` that runs as one site with a sidebar panel) in a team module, and how to eject a starter to extend its experience
