Rhizome 0.53 puts **chat beside whatever you're looking at**. In every section of the workbench, the right pane now has a Chat tab where Claude Code or Codex sees the note, view or type on screen, can read the page when it needs more, and works with few permission prompts. You pick the agent, model, reasoning and permission mode in the composer itself. This release also keeps a repository's agent files current when Rhizome is upgraded, makes the live indexer agree with `rzm index`, and loads Delivery about ten times faster.

## Chat beside your work

- **One right pane, one toggle.** In Notes, Chat is a tab after Info, Outline and Graph, or after Record for a selected row. Elsewhere the pane holds Chat alone and appears only when you open it. The top bar's far-right button and `]` toggle the pane, and ⌥⌘B opens Chat with the cursor in the message box. ⌘B now toggles the left sidebar.
- **It knows what's on screen.** Each message carries the note, view, type or section you're on as a chip you can remove. The agent can also read your section's visible text with a `page_text` tool.
- **Few prompts.** Chat sessions default to a new Auto permission mode (Claude auto mode, Codex "Approve for me"). Commands, edits and tool calls show as one line each, and only escalations ask for Allow or Deny.
- **Choose from the composer.** One picker beside Send (⇧⌘M) lists Claude Code's and Codex's models, showing the latest of each family with search for the rest, plus a Reasoning column (⇧⌘E). A menu beside it (⇧⌘A) offers Ask first, Auto, Accept edits and Full access. New chats start on the latest Opus when Claude Code is ready, otherwise on the latest Sol. Switching model or effort applies from the next turn; switching agent starts a new chat.
- **Setup help in place.** When the chosen agent is signed out or not installed, a notice above the composer gives the command to copy or the install link, with Check again. Rhizome Desktop now finds both agents from your login shell's PATH, Homebrew and `~/.local/bin`, and Settings → Chat shows each agent's status with a switch to hide it from the picker. This replaces the chat setup card and the Agent page's harness selects.
- **It's an Agent session.** Open in Agent continues the conversation on the Agent page.

Agents also know more about Rhizome itself. The `rhizome` skill can now explain what Rhizome is and what each view offers, recommend and install starters based on the repository, customize note types, schema and views, and automate vault work with scripts, module actions and scheduled tasks. Chat routes questions about Rhizome to it. First-time setup, including Rhizome Desktop's setup sheet, lists optional add-ons such as AO KB and Compounding, unchecked.

## Upgrades keep agent files current

Upgrading a repository's Rhizome used to move the pin but leave the skills and managed guidance from the previous release until someone reran `rzm init`. Now they upgrade together.

- **In Rhizome Desktop**, "Update to X" opens a review of the pin and file changes, then installs the new version, refreshes skills and managed guidance with it, and restarts the runtime. A failed step offers Retry, and the result includes a commit command to copy. When a worktree's generated files are behind the Rhizome it runs, for example after a teammate bumps the pin, the toolbar offers "Update Rhizome files".
- **From the command line**, `rzm update` runs the new executable's `rzm init` whenever it changes the Rhizome the current repository runs.
- **Legacy upgrades finish without losing edits.** `rzm init` recovers verified ownership of older generated files from Git history, so unchanged legacy schemas move into modules and get current features. Files it can't verify stay untouched and are listed with diffs and explicit `--take` and `--keep` choices.

## Faster, more reliable indexing and views

- **The live indexer matches `rzm index`.** Live indexing uses the configuration the runtime has applied, writes code-to-note links it previously skipped, and rebuilds parsers when code settings change. Index version v1.18.0 repairs existing indexes once without sending text to the embedding provider.
- **Interruptions cost less.** A cancelled change keeps its scope instead of forcing a full-vault recrawl, interrupted embedding work no longer spins or counts as a failure, and vectors the provider already returned are kept.
- **Fewer provider calls.** Changed notes are embedded in groups packed to the provider's limits, for example 50 notes in one call instead of 50.
- **Delivery loads about 10× faster**, in roughly 0.17 seconds on a warm runtime, by reading specs and stories in nested, parallel queries. Spec and effort record pages and the AO KB Knowledge site got the same treatment.

## Notes workspace

- A **Files** panel at the bottom of the Notes sidebar shows the vault's folders and notes as an expandable tree, reveals the open note and remembers its height and open folders. It replaces the Folder panel.
- Delivery's stages (Shaping, Ready, Planned, Active and History) are tabs on the Delivery group page.
- "Untyped + ambiguous" on the All notes Overview opens a list of those notes.
- Clicking a title in a table opens the note. Cmd/Ctrl-click opens it beside the current one.

## Fixes

- Ontology publication no longer fails on valid empty required link lists. GraphQL queries and query recipes reject an unpublished schema change instead of returning an empty result that looks complete.
- `rzm init` adds the Codex loopback profile correctly when `.codex/config.toml` already has a `[features]` table.
- On macOS, a user-owned Rhizome Desktop can update by replacing the app's contents in place, with validation and rollback, and falls back to the full replacement otherwise. Some updates may still ask for an administrator password.

The README and user guides now start from Rhizome Desktop. Terminal and scripted use moved to a new command-line reference.

## Upgrading

- **macOS Desktop** updates itself. Homebrew users can run `brew upgrade --cask rhizome-desktop`.
- **Linux Desktop** updates itself in the app, or you can download the new AppImage.
- **Repositories**: accept the app's "Update to X" offer, or run `rzm update`, and the generated agent files refresh with the new version. Repositories that follow the app's Rhizome show "Update Rhizome files" when they need a refresh. Review and commit the resulting changes.
- **Shortcuts**: ⌘B now toggles the left sidebar (Rhizome Desktop's View menu moved it from ⌃⌘S), and ⌥⌘B shows Chat.
- **Chat** needs Claude Code or Codex installed and signed in on the same machine.
