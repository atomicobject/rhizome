2. Go (GPT-6.1 Sol, xhigh, priority tier): permission mode `auto` in both drivers and as the chat default, view context on messages with a store migration, session instructions, and the `rhizome_page` MCP server with its relay endpoints.
3. Desktop (GPT-6.1 Sol, xhigh, priority tier): the toolbar's right-pane button from the page's `paneCollapsed` report, the View menu's ⌘B sidebar accelerator and Show Chat on ⌥⌘B, and the `pane` and `chat` page commands.
4. Merge the three branches, run the gates, check the real app with a live harness, review with Sol, and open the pull request.

## Original Intended Delivery

From any section, a person opens Chat beside what they are looking at, asks about it without describing it, and the agent reads the page or acts on it, interrupting only for risky actions. The conversation continues on the Agent page.
