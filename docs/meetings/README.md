# Meetings

## Summary

Use this folder for raw transcripts or structured meeting notes that serve as source material for durable specs, decisions, and reference docs.

## Rules

- prefer one canonical transcript per meeting
- use `YYYY-MM-DD-<slug>.txt` for raw transcript filenames
- treat these files as source inputs; durable conclusions belong in ontology-backed notes elsewhere in `docs/`
