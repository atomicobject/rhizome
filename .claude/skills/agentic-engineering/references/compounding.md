# Compounding

For an effort, load `query-recipe run --id closure-drift-pack` when equivalent current context is not already available; otherwise reuse it and refresh only changed sources. Promote repeated, evidenced friction into durable leverage only when it would reduce future delivery cost: a test, script, template, skill, validation rule, capability request, or scoped follow-up. Name the recurrence, evidence, proposed improvement, owner, and smallest next action.

Do not turn every cleanup into process or create a compounding artifact when no repeated friction exists. One-off defects belong in the current fix or its reconciliation path. Ask before an improvement that changes team policy, security posture, or access, unless the user already approved that change.
